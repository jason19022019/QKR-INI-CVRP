# QKR-INI-CVRP

Code accompanying the manuscript

"A Two-Phase Hybrid Framework for the Capacitated Vehicle Routing Problem Using Quantum Kernel Clustering with Quantum Knapsack Repair"

## Requirements

Python 3.11

Packages

- pennylane
- pennylane-machine-learning
- numpy
- scipy
- scikit-learn
- networkx

Install

pip install -r requirements.txt

## Running

python main.py

The repository contains the implementation of

- Quantum Kernel K-Means
- QKR-INI
- QAOA Knapsack Repair
- Benchmark evaluation
